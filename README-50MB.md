# رفع ملفات حتى 50MB — تعليمات التفعيل

1. ارفع **محتويات** هذا المجلد إلى جذر مستودع GitHub مع الحفاظ على مجلد `api/` وملفيه `study.js` و`upload.js` (لا ترفع ZIP كملف واحد). احذف `study.js` القديم من جذر المستودع لتجنب الالتباس.
2. في Vercel > Project > Settings > Environment Variables: احتفظ بـ `OPENAI_API_KEY`، وتحقق من توصيل Vercel Blob PRIVATE بالمشروع (متغيرات الاتصال تُضاف تلقائيًا). **أضف متغيرًا جديدًا `STUDY_ACCESS_CODE` بقيمة سرية طويلة يصعب تخمينها** في Production. أعطِ الرمز فقط للمستخدمين المسموحين.
3. أعد نشر المشروع من Vercel، ثم افتح رابط الموقع على Vercel وجرب PDF صغيرًا أولًا، وبعده ملفًا أكبر من 4.5MB. لم يتم اختبار تشغيل OpenAI/Blob حيًا هنا، لذلك تحقق من Logs في حال أي خطأ.
4. الموقع إذا كان يعمل من GitHub Pages يستخدم عنوان Vercel المثبت في `ai-study.js`. راجع `API_BASE` إن تغيّر نطاقك.

**تنبيهات لازمة:** هذا رمز مشترك مؤقت **وليس نظام تسجيل دخول آمنًا للطلاب**؛ قبل فتح الموقع للعموم أضف هوية مستخدم حقيقية مع حد طلبات وميزانية إنفاق وتنظيف الملفات المهجورة. رفع 50MB لا يعني أن كل ملف يمكن تلخيصه: ملفات PDF الكبيرة أو المصوّرة قد تتجاوز حد OpenAI أو زمن المعالجة؛ ملفات DOCX/PPTX التي نصها أطول من 180 ألف حرف تُرفض برسالة صريحة بدل تلخيص جزء دون علم الطالب. يرفع Blob الملف بطريقة مباشرة ولا تمر بايتاته من خلال طلب Vercel API. يقرأ خادم Vercel الملف الخاص بعد الرفع، ثم يحذفه بعد إنهاء المعالجة عادةً؛ إذا انقطع التنفيذ قبل finally فقد يلزم تنظيف دوري للملفات المهجورة. في بعض نسخ SDK قد لا يدعم العميل رفع Private على الوجه المتوقع؛ تحقق من SDK الفعلي وأخطاء الإنتاج.

مراجع: https://vercel.com/docs/vercel-blob/client-upload و https://vercel.com/docs/vercel-blob/private-storage و https://vercel.com/docs/functions/limitations
