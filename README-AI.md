# إضافة المساعد الدراسي إلى دليل التخصص

تم الاحتفاظ بملفات الموقع الأصلية مع إضافة قسم **المساعد الدراسي AI**. طالب واحد يختار **تلخيص** أو **أسئلة** أو **الاثنين**؛ لا تُنفذ كل العمليات تلقائيًا. لغة النتيجة تُختار حسب لغة الملف.

## طريقة النشر

1. افتح مستودع GitHub الحالي، وارفع **كل الملفات الموجودة في هذا المجلد** إلى جذر المستودع (أو اسحب محتويات ZIP إلى GitHub بعد فك الضغط). **لا تحذف الملفات الأصلية**. تأكد أن `api/study.js` موجود ضمن مجلد `api` وليس في الجذر، و`package.json` موجود في الجذر.
2. بما أن المستودع مربوط مسبقًا بـ Vercel، كل `Commit` على `main` ينشئ عملية نشر جديدة. من Vercel تحقق أن آخر Deployment بحالة Ready.
3. في Vercel > Project > Settings > Environment Variables، تحقق من وجود `OPENAI_API_KEY` في **Production**. **لا تضع المفتاح في GitHub أو في ملفات الواجهة**. عند تغيير متغير البيئة أعد نشر المشروع من Deployments > Redeploy حتى يدخل حيز التنفيذ.
4. افتح رابط موقعك على Vercel واضغط **المساعد الدراسي AI** من القائمة أو الرئيسية، وارفع PDF / DOCX / PPTX أصغر من 3MB وحدد عملية واحدة ثم اضغط «ابدأ الآن».
5. إذا كنت تستخدم نسخة GitHub Pages أيضًا، راجع `STUDY_API_URL` في `ai-study.js` وحدّثه إلى رابط نطاق **Production** الحقيقي الموجود في Vercel إذا اختلف عن الرابط الافتراضي. الاستضافة على Vercel تستخدم `/api/study` تلقائيًا.

## مهم قبل إطلاق الميزة للطلاب

- إضافة متغير البيئة لا تجعل الميزة تعمل وحدها: يجب رفع `api/study.js` ونشر المشروع. يحتاج حساب OpenAI API إلى رصيد أو إعداد فوترة. واجهة ChatGPT Plus ليست رصيد API.
- API الحالي عام، ولذلك قد يستهلك أي زائر حصتك المدفوعة. أضف تسجيل دخول وتحديد طلبات لكل طالب (باستخدام مخزن دائم مثل Redis) وميزانية إنفاق وتنبيهات من لوحة OpenAI، قبل نشر الموقع علنًا للطلاب.
- Vercel Functions لها حد 4.5MB للطلب، ولذلك حددنا الملف بـ 3MB. ملفات DOCX/PPTX تُقرأ كنص، ولا تشمل الصور المضمنة. ملفات PDF الممسوحة ضوئيًا قد تعطي نتائج متفاوتة. النتائج تلقائية وينبغي تدقيقها.
- الموقع الأصلي ما يزال يحتوي على صفحة `admin.html`؛ تأكد أيضًا من عدم تخزين أي رمز GitHub فيها أو في `content.json`.
