# إصلاح رفع الملفات الخاصة مؤقتًا

ارفع إلى GitHub الملفات التالية فقط مع الحفاظ على المسارات:
- `index.html`
- `ai-study.js`
- `api/upload-small.js` **ملف جديد داخل مجلد api**

لا تحذف `api/study.js` ولا تغيّر بيانات التخزين. بعد أن تصبح حالة Vercel Ready، اختبر ملف PDF صغيرًا من موقع Vercel نفسه. حد الرفع **2.5 MiB مؤقتًا** لأن الملف يعبر Vercel Function بصيغة base64؛ هذا ليس حل 50MB. احذف لاحقًا وظيفة upload-small بعد نقل الرفع إلى خدمة تدعم روابط رفع موقعة خاصة (مثل S3).

المساعد متاح بدون تسجيل؛ قبل إتاحته لجميع الطلاب اضبط قيود الطلبات وموازنة OpenAI. تخزين Blob الخاص يبقى كما هو، ولا ترسل المفاتيح لأي أحد.

إذا ظهر خطأ في الدراسة بعد نجاح الرفع، افحص `api/study` في Vercel Logs، فهو مسار مستقل.
